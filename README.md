# javascript-lotto-precourse
### 📖 프로젝트 소개
사용자로부터 구입 금액을 입력받아 구매 가능한 개수만큼 로또 번호를 자동으로 생성하고, 입력한 당첨 번호 및 보너스 번호를 기준으로 결과를 비교하여 당첨 통계(당첨 결과, 수익률)를 출력하는 프로그램

### 주요 기능
<b>1. 구입 금액 입력</b> : 사용자가 입력한 금액(1장당 1,000원)에 따라 구매 가능한 로또 개수 계산  
<b>2. 로또 번호 자동 생성</b> : 각 로또 번호는 1~45 사이의 중복되지 않은 숫자 6개로 구성  
<b>3. 당첨 번호 및 보너스 번호 입력</b> : 사용자가 직접 입력한 당첨 번호와 보너스 번호를 기반으로 결과 판단  
<b>4. 당첨 통계 계산</b> : 각 로또 번호와 당첨 번호를 비교하여 일치 개수를 계산  
<b>5. 수익률 계산</b> : 총 상금 대비 구입 금액을 계산하여 수익률(%) 출력

<br>
